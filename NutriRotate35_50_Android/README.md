# NutriRotate 35-50 (Native Android App)

Dark-theme, 2D flat/emoji healthy diet & weekly grocery rotation app for ages **35-50** (Kerala & India staples).

## Option 1: Build APK in the Cloud (No Android Studio Needed)
1. Create a free repository on GitHub and upload all files inside this `NutriRotate35_50_Android` folder (make sure `.github/workflows/build-apk.yml` is included).
2. Open the **Actions** tab in your GitHub repo and wait ~3 minutes for **Build Android APK** to finish.
3. Click the completed run and download **NutriRotate-35-50-debug-apk** to get `app-debug.apk` on your Android phone.

## Option 2: Run via Android Studio on PC
1. Open **Android Studio** -> **Open** -> select this `NutriRotate35_50_Android` folder.
2. Wait for Gradle sync to finish.
3. Connect your Android phone via USB (with **USB Debugging** enabled) and click **Run**.
